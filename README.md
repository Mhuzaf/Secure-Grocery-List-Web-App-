# Web Project

Web Project for Block 3 - Web App Development

## Running locally

Make sure you have deno installed, Visit the [official site](https://deno.com)
for instructions.

```sh
git clone https://github.com/pnbread/webproject
cd webproject
deno install # install dependancies (jsr)
deno task start
```
